# Handsontable

The grid is [Handsontable](https://handsontable.com/) **0.12.6**, loaded from cdnjs:

    //cdnjs.cloudflare.com/ajax/libs/handsontable/0.12.6/handsontable.full.min.js

## Why it is not updated

Handsontable changed its license with version 7:

| Version | License |
| --- | --- |
| 0.12.6 (2015, the one used here) | MIT |
| 6.2.2 (2018) | MIT, the last open source release |
| 7.0.0 and later, up to 18.x | `SEE LICENSE IN LICENSE.txt`, commercial, free for non commercial use only |

Updating to a current version is therefore a licensing decision for this project, not only a
technical one. If the library is ever updated, 6.2.2 is the version that keeps the project on MIT.

There is work involved either way, the code uses two things that no longer exist in recent versions:

* the jQuery plugin, `$("#table-wrapper").handsontable({...})`, which was dropped,
* `table.mergeCells.mergedCellInfoCollection`, an internal of the merge cells plugin, replaced by
  `getPlugin('mergeCells')`.

## The internals that are used

**The merged cells collection.** `extractData()` reads the merge of a cell with
`table.mergeCells.mergedCellInfoCollection.getInfo(i, j)`, and `applyState()` writes into the same
collection.

Setting `mergeCells` through `updateSettings()` does **not** work in this version: the plugin reads
that setting when the grid is created and never again, so the settings change but nothing is merged.
The collection has to be edited directly:

```js
var collection = table.mergeCells.mergedCellInfoCollection;
collection.splice(0, collection.length);          // drop the previous merges first
table.loadData(data);
collection.setInfo({row: 1, col: 2, rowspan: 1, colspan: 3});
table.render();
```

The order matters. Merges left over from the previous content can point outside of the new grid,
and `extractData()` then reads an undefined cell and fails in `getWidths()`.

`setInfo()` keeps the object it is given, so pass it a copy when the source is a constant.

**The cell meta.** The text alignment set with the context menu is stored by Handsontable as a
`className` on the cell meta (`htLeft`, `htCenter`, `htRight`, `htJustify`, `htTop`, `htMiddle`,
`htBottom`). `extractData()` reads it with `getCellMeta(i, j)` and the shared links carry it, see
[share-links.md](share-links.md). It is not part of `getData()`, which is easy to forget: the first
version of the shared links lost every alignment.

**`afterRender`.** The output is regenerated by `genPTT` hooked on `afterRender`, so anything that
changes the grid only has to call `render()`.
